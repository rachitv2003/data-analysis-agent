## Issues Implemented

### 1 — Clustering continuity (`graph/nodes.py`)
Added `_REUSE_DERIVED_INSTRUCTION` constant and wired it into `_build_prompt`. Instructs the agent to check the "Previously saved derived datasets" manifest first before re-running any analysis from scratch.

### 2 — Context window bar uses actual tokens (`index.html`)
- Added `var _lastActualPromptTokens = 0` variable
- Updated `_updateCtxBar()` to use actual prompt tokens when available (no `~` prefix), falling back to estimate (`~`) before any query runs
- In `appendTurn()`: sets `_lastActualPromptTokens = breakdown.total_prompt` and calls `_updateCtxBar()` immediately after each query

### 3 — Remove History from breakdown (`index.html`)
Removed `['history','History']` row from `_renderBreakdown` keys array.

### 4 — Today metric uses local time; Last query replaces This Session (`base.html` + `index.html` + `stats.py`)
- `stats.py`: filter uses `func.datetime(..., "localtime")` — SQLite converts UTC stored timestamps to server local time (IST)
- `index.html` sidebar HTML: "This session" → "Last query", Queries row removed, "Today (UTC)" → "Today"
- `base.html`: replaced sessionStorage accumulator with simple last-run display; removed `_TU_KEY`, `_getSession()`, `_saveSession()`, `_tuRenderSession()`. `tuAddRun(ti, to)` now just writes the single run's values.

### 5 — Separate breakdown from steps (`index.html`)
`appendTurn()` now renders two independent collapsible sections per turn:
- "▶ Token breakdown" — shows prompt token breakdown table (only if breakdown data present)
- "▶ N steps" — shows the step inspector blocks

Previously they were merged into one panel.

### Additional — Remove 📝 button (`index.html`)
Removed `showNotesForDataset()` function, its callers in Jinja2 template, `_dsRowInner`, and `_attachDsRowListeners`.
