### Database tab (new capability — C28)
New `[Database]` tab alongside `[Analyse]` in the main area. Session-scoped: shows the active session's uploaded + derived datasets, their schemas, and their lineage.

**Layout:** header bar | lineage graph (left) + schema panel (right) | dataset strip (bottom)

**Lineage graph:** SVG DAG, topological layout (uploaded left, derived right), blue/green/amber-border nodes, drag to pan, scroll to zoom, Fit button

**Schema panel:** populated on node/chip click via `GET /datasets/{id}`; shows column dtypes, context notes (editable), derivation code (collapsible), parent links; actions: 🧹 Clean (uploaded), 🔄 Re-derive (derived), 🗑 Delete

**Dataset strip:** horizontal scrollable chips, order: uploaded first then derived by age; bidirectionally synced with DAG selection

**No-session state:** shows all uploaded datasets (flat graph, no edges) with banner prompting the user to start a session

**Actions:** Clean, Re-derive, Delete (per dataset in schema panel); Clear database (header, calls `DELETE /datasets`)

**New modals:** `clear-db-modal` (confirm full wipe)

**New JS globals:** `switchTab`, `loadDatabaseTab`, `renderLineageDAG`, `selectDataset`, `_dbDatasets`, `_dbSchemaCache`
