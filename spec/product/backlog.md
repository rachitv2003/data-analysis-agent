# Product Backlog

Capabilities approved for the next build phase. All items below are scoped and ready to spec when picked up.

---

## Quick Wins

- [x] **Excel upload** — add `.xlsx` / `.xls` to the ingestion pipeline (`pandas.read_excel`); fits directly into C1 upload flow with no architecture changes
- [x] **Session rename** — let users rename a session from the sidebar; pure UI + one PATCH endpoint
- [x] **Suggested follow-up questions** — after each answer, show 2–3 clickable follow-up questions generated by an extra LLM call
- [ ] **Chart download** — "Save as PNG" button on each Plotly chart; Plotly JS `toImage` API, no backend changes

---

## Session Management

- [x] **Select and clear sessions** — checkboxes in the Sessions sidebar to bulk-select and delete multiple sessions at once; also a "Clear all sessions" action (analogous to the existing dataset clear-all)

---

## Dataset Panel

- [ ] **Column list in dataset panel** — expand a dataset row to reveal its column names (already stored in `columns_json`); collapsed by default, click to expand; no new DB fields needed

---

## Export

- [ ] **Export conversation** — download the current session as a formatted PDF or Markdown file; includes all Q&A turns, rendered answers, and chart placeholders; useful for sharing analysis with non-technical stakeholders

---

## Analysis

- [x] **Natural language data cleaning** — agent interprets cleaning instructions ("remove rows where revenue is null", "rename column X to Y", "parse dates in column Z") and applies them as pandas mutations with a confirmation step before overwriting the dataset
- [x] **Persistent agent memory** — user can save facts that inject into every prompt for a dataset or globally ("fiscal year starts in April", "revenue is always in USD"); extends the existing dataset context system

---

## Notes

- Items are listed roughly in ascending implementation complexity within each group
- Each item needs a spec (`/spec-new-capability`) before implementation starts
- Data quality report (auto-profiling on upload) is a candidate for a future phase but not in this batch
