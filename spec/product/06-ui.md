# UI

## UI Type

Web dashboard — server-rendered HTML via FastAPI + Jinja2. No JS build step required for v0.1.

## Tech Stack

Python 3.12 + FastAPI + Jinja2 + plain HTML/CSS (no frontend framework).

## Views / Screens

### Screen: Main Page

**Purpose:** Upload a CSV and ask natural language questions about it.

**Key elements:**
- Stub mode banner (yellow, top of page) — shown when `llm_provider = stub`
- Upload section: file input (.csv only) + Upload button + dataset summary card on success
- Dataset selector: dropdown of all uploaded datasets
- Question textarea: user types their natural language question
- Ask button + loading spinner
- Answer display: plain text answer rendered below the question box

**Actions available:**
- Upload a CSV file
- Select a previously uploaded dataset
- Type and submit a question
- View the answer

## Error States

- Upload failure: red error message below the upload button
- Ask failure: red error message in the answer area
- Loading state: spinner replaces the Ask button while waiting
- Empty file / wrong format: inline validation message before submission

## Stub Banner

When `llm_provider = stub`, a yellow banner appears at the top of every page:

```
⚠ Running in stub mode — set GEMINI_API_KEY for real answers
```

This banner is injected via the Jinja2 base template (`base.html`) so it cannot be omitted on any page.
