# UI

## UI Type

Web dashboard — server-rendered HTML via FastAPI + Jinja2. No JS build step. All interactivity is vanilla JS in the template files.

## Tech Stack

Python 3.12 + FastAPI + Jinja2 + plain HTML/CSS/JS (no frontend framework, no bundler).

---

## Layout

Two-panel app shell rendered by `base.html` + `index.html`:

```
┌─────────────────────────────────────────────────────┐
│  Header: "Data Analysis Agent"          [Memory]     │
├──────────────┬──────────────────────────────────────┤
│  Sidebar     │  Main                                 │
│              │  ┌──────────────┬──────────────────┐  │
│  Sessions    │  │  Datasets    │  Upload           │  │
│  list        │  └──────────────┴──────────────────┘  │
│              │  ┌────────────────────────────────┐   │
│  ──────────  │  │  Conversation thread + query   │   │
│  Token       │  └────────────────────────────────┘   │
│  usage       │                                       │
└──────────────┴──────────────────────────────────────┘
```

### Responsive breakpoints

- `≤ 960 px`: sidebar stacks above main, both full-width
- `≤ 640 px`: datasets and upload cards stack vertically; sidebar sub-panels stack

## Components

### Header (`base.html`)

- App name + tagline
- **Memory** button — opens the persistent memory modal
- Stub mode banner (yellow, below header) shown when `llm_provider == "stub"`:
  `⚠ Running in stub mode — set DATA_ANALYST_GEMINI_API_KEY in your .env for real answers`

### Sidebar — Sessions panel

- List of past sessions (name or first question, turn count, relative timestamp)
- Per-session: checkbox (bulk select), click body to resume, ✏ rename inline (Enter to save, Escape to cancel)
- **Delete selected** button — appears when ≥ 1 checkbox checked; opens confirmation modal
- **+ New** button — clears thread, deselects active session
- **Clear all sessions** button (footer, danger style) — opens confirmation modal

### Sidebar — Token usage widget

- Model name (uppercased via CSS)
- Two columns: This session (tokens in/out, queries, estimated cost) | Today UTC (same fields)
- Storage row: dataset count + total rows across all datasets
- Session stats are accumulated in `sessionStorage`; daily stats fetched from `GET /stats/daily`
- Cost is computed client-side from a built-in pricing table; shows "N/A" for unknown models

### Datasets card

- Scrollable list of uploaded datasets (max-height 200 px)
- Per dataset row: checkbox, filename + dimensions (rows × cols), **▸ cols** toggle, 🧹 clean button, 🗑 delete button
- **▸ cols** expands a chip list of column names stored in `columns_json`
- Inline delete confirm: hides the dataset row's content, shows "Delete? / Cancel" — no `confirm()` dialog
- Bulk actions: **Select all / Deselect all**, **Delete selected** (custom modal), **Clear all** (custom modal)
- Dataset notes panel (below list): shows context for the single selected dataset; inline edit

### Upload card

- Drag-and-drop zone (accepts files and folders)
- Folder drop: reads `_notes.txt` / `context.txt` / `readme.txt` etc. as folder-level notes; matches `<stem>.notes.txt` files per data file
- **Choose files** button → hidden `<input type="file">` (`.csv .tsv .txt .json .xlsx .xls`)
- **Staged file list**: files wait in a client-side `Map` before upload — user can rename, add typed notes, attach a `.txt`/`.md` notes file, or remove
- **Upload N file(s)** button — uploads up to 3 files concurrently; per-file queue row shows ⏳/✓/✗ and inline "Use existing / Upload anyway" on 409 duplicate

### Conversation card

- **Thread** (`role="log"`, `aria-live="polite"`) — appended turns, smooth scroll to new turn
- Per turn: question in blue, timestamp + elapsed time, optional **⚠ Best effort** badge, rendered Markdown answer (tables, bold, bullets, code, headings), iteration count + token counts, **Datasets used** detail disclosure, **Steps inspector**
- **Steps inspector**: collapsible toggle showing each agent iteration — code block (dark theme) + result/error block; **Copy** button per step; error steps show a red "✕ Error" badge
- **Follow-up chips**: 2–3 clickable question suggestions appended after each answer
- **Export MD** button — downloads conversation as a `.md` file
- **Question textarea** — Enter to submit (Shift+Enter for newline)
- **Ask** button — disabled while running, shows spinner
- **Stop** button — shown while a query is running; calls `AbortController.abort()` to cancel the fetch
- **Progress row** — shown while running: elapsed timer, iteration progress bar (`Step N / M`), reads from `GET /runs/current`

### Modals

All modals use `.modal-overlay` class. Backdrop click and Escape key close any open modal. First focusable element receives focus on open.

| Modal ID | Trigger | Purpose |
|---|---|---|
| `memory-modal` | Header Memory button | Edit persistent memory injected into every query |
| `clean-modal` | 🧹 per dataset | NL data cleaning: describe operation → preview code + row counts → apply |
| `clear-sessions-modal` | "Clear all sessions" | Confirm bulk session delete (all sessions) |
| `del-sel-sessions-modal` | "Delete sel." in sessions | Confirm delete of checked sessions |
| `clear-all-datasets-modal` | "Clear all" in datasets | Confirm delete all datasets + sessions |
| `del-sel-modal` | "Delete selected" in datasets | Confirm delete of checked datasets |

## Error States

| Situation | Feedback |
|---|---|
| Upload failure | ✗ icon in queue row + error text inline |
| Duplicate file (409) | ⚠ in queue row + "Use existing / Upload anyway" buttons |
| Ask failure | Red error message in `#ask-status` |
| Query cancelled | Amber "Query cancelled." message |
| Agent best-effort | Yellow **⚠ Best effort** badge on the turn |
| Dataset delete failure | Inline error row with Dismiss button |

## Key JS Globals

| Symbol | Purpose |
|---|---|
| `esc(s)` | HTML-escape (`&`, `<`, `>`, `"`, `'`) |
| `openModal(id)` / `closeModal(id)` | Modal open/close with focus management |
| `announce(msg)` | Writes to `#aria-live` for screen readers |
| `tuAddRun(ti, to)` | Accumulates token counts in sessionStorage |
| `_askController` | `AbortController` instance for the current query fetch |
| `_staged` | `Map` of staged file entries before upload |
| `currentSessionId` | UUID of the active session, or `null` |

## Accessibility

- `role="log"` + `aria-live="polite"` on the conversation thread
- `role="list"` / `role="listitem"` on session and dataset lists
- `aria-label` on all icon-only buttons
- `aria-modal="true"` + `aria-labelledby` on all modals
- `role="progressbar"` with `aria-valuenow` on the iteration bar
- `aria-live="polite"` on `#ask-status` and `#progress-row`
- `#aria-live` hidden live region for programmatic `announce()` calls
- `type="button"` on all non-submit buttons
